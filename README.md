# Moving Day · วันย้ายบ้าน

Moving from one AI to another, in Thai and English.
https://nanobotco.github.io/moving-day/

`docs/index.html` is the site. Platform steps and laws live in `tools/data.js`, the copy-paste
prompts in `tools/prompts.js`; `tools/build.py` puts both into the page. `tools/card.py` draws
`docs/card.jpg`; `tools/serve.py` serves `docs/` on port 8913.
